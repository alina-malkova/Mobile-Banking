TECHNICAL NOTES
============================================================

1. HALTON DRAWS DOCUMENTATION:
   This script uses 100 Halton draws (base 2) as claimed in the paper.
   The existing Stata code (phase7_mixed_logit.do) used only 50 pseudo-
   random draws in its simulation loop. Halton sequences provide better
   coverage of the unit interval than pseudo-random draws, yielding more
   accurate simulation of the mixed logit integral. With 500 Halton draws,
   the simulation error is typically < 0.1% of the true integral value.

2. DISTRIBUTIONAL COMPARISON:
   Normal:    gamma_r = mu + sigma * Phi^{-1}(h_r)
     - Allows negative values (some individuals have gamma < 0)
     - Symmetric heterogeneity around the mean

   LogNormal: gamma_r = exp(mu + sigma * Phi^{-1}(h_r))
     - Ensures gamma > 0 (all individuals have positive effect)
     - Right-skewed heterogeneity distribution
     - E[gamma] = exp(mu + sigma^2/2)
     - SD[gamma] = sqrt((exp(sigma^2) - 1) * exp(2*mu + sigma^2))

3. MODEL SELECTION:
   BIC comparison provides a formal criterion for choosing between
   Normal and LogNormal. If BIC values are close (within ~10 units),
   neither distribution is strongly preferred, and both counterfactuals
   should be reported.

4. RELATIONSHIP TO FINITE MIXTURE:
   The mixed logit and K=4 finite mixture are alternative approaches to
   capturing heterogeneity. The finite mixture estimates ~4 discrete types;
   the mixed logit estimates a continuous distribution. If both yield
   similar counterfactual magnitudes, the results are robust to how
   heterogeneity is modeled.
